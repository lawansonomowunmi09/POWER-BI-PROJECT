  Power BI Hospital Data Analysis Project
 This project focuses on analyzing hospital data to uncover key insights that support operational efficiency and improve patient care. Using Power BI, I transformed raw healthcare data into an interactive and visually compelling dashboard for better decision-making.
The dataset included information on patient records, admissions, treatments, hospital departments, and billing details. I began by cleaning and transforming the data using Power Query, ensuring consistency, handling missing values, and standardizing formats across all fields.
Data modeling was performed by establishing relationships between tables to enable accurate analysis. I then created calculated measures and KPIs using DAX functions such as SUM, COUNT, AVERAGE, and CALCULATE to track important metrics.
   The dashboard provides insights into:
Patient admission trends
Departmental performance
Treatment costs and revenue analysis
Patient demographics and distribution
Length of hospital stay and resource utilization
